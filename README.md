# 🏐 Volleyball Mod

**Turn your Minecraft world into a sports court!**

A lightweight, multiplayer-friendly mod that adds a fully functional volleyball with custom physics, serving, passing, and spiking mechanics.

---

</div>

## ✨ Features

* **Authentic Volleyball Block:** Easily craftable with survival-friendly vanilla materials.
* **Physics & Impulse:** Works dynamically using falling block physics — launch, spike, and keep the ball in the air!
* **Multiplayer Ready:** Fully synced server-client mechanics designed for playing matches with friends.

---

## 🎮 How to Play & Controls

| Action | Control | Description |
| :--- | :--- | :--- |
| **Serve / Lift** | `Shift + Right Click` *(Empty Hand)* | Lifts the volleyball off the ground into the air to start the rally. |
| **Pass / Set** | `Right Click` *(on airborne ball)* | Gently tosses the ball upward for a teammate to set up a play. |
| **Spike / Attack** | `Left Click` *(on airborne ball)* | Launches the ball forward in the direction you are looking! |
